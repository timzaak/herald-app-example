## 角色列表

### App 用户

- **技术标识**: `app_user`
- **定义**: Herald 某 realm 内、通过本 Client App 接入的终端使用者。
- **典型目标**: 登录、注册、找回密码、保持会话、退出登录,以及访问 realm 内受保护的应用功能。
- **边界**: 仅在运营预设的单一 realm/client 范围内活动;不做跨 realm 操作,不持有运营/管理后台权限。

### 子集与状态修饰

以下不是独立角色,而是「App 用户」在特定故事场景下的状态子集。故事中可直接以「App 用户」引用,并以验收标准的 Given 条件描述该状态。

| 修饰 | 技术语义 | 出现于 |
|---|---|---|
| 新用户 | 尚未在本 realm 注册的访问者,正尝试创建账号 | US-AUTH-005 注册 |
| 已登录的 App 用户 | 当前持有有效会话(访问凭证或可刷新的刷新凭证) | US-AUTH-007 会话持久、US-AUTH-008 退出登录 |
| 忘记密码的 App 用户 | 会话状态不适用,需通过邮箱验证码重置密码 | US-AUTH-006 找回密码 |
| 已开启 TOTP 二次验证的 App 用户 | realm/账号侧开启了 TOTP,登录需二次确认 | US-AUTH-003 TOTP 二次验证 |
